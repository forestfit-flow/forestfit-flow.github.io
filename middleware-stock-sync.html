STOCK · MIDDLEWAREFORESTFIT INTERNAL WORKSPACE
01 / STOCK SYNC

미들웨어 재고장 연동

재고장 K열 수량을 상품명·색상·기장·사이즈 기준으로 매칭해 미들웨어 D열에 반영합니다.

1

재고장 파일 첨부

첫 번째 탭은 제외하고 두 번째 탭부터 B·C·E 병합값과 F·K열을 읽습니다.

재고장 파일을 선택해주세요.
2

미들웨어 품목정보 파일 첨부

C열에서 상품명과 옵션정보를 함께 분석합니다. 첨부된 원본 파일의 내부 구조와 양식을 그대로 유지한 채 D열 수량만 수정합니다.

1단계 완료 후 첨부할 수 있습니다.
3

상품명 구성 확인

재고장 첫 번째 탭의 C20 이하 상품명과 2번 첨부 미들웨어 품목정보 파일의 상품명을 비교합니다.

두 파일을 첨부하면 상품명 구성 차이를 자동으로 확인합니다.
4

상품 및 옵션 매칭 시작

상품명 구성 확인 후 수량 매칭을 실행합니다.

파일을 순서대로 첨부해주세요.
5

매칭 실패 확인

정상 항목은 표시하지 않으며, 상품명은 한 번만 표시하고 실패 옵션을 아래에 묶어 보여줍니다.

매칭 실행 후 실패 항목이 표시됩니다.
6

결과 파일 다운로드

매칭된 행만 미들웨어 D열에 반영하고, 매칭 실패 항목은 기존 D열 값을 유지합니다.

매칭을 먼저 실행해주세요.
02 / PRODUCT MAPPING

미등록 상품 매핑

셀메이트 옵션과 판매처별 미들웨어 품목코드를 비교해 매핑 검증 결과를 만듭니다.

검증 기준 · 셀메이트 C열 바코드의 하이픈(-) 제거 → 판매처 H열 품목코드 대조 → 셀메이트 B열 옵션과 판매처 G열 옵션의 색상·기장·사이즈 각각 확인 → E열 괄호 상품명 비교(있는 경우). 옵션 순서가 다른 하프클럽 형식도 자동 해석하되 불명확한 값은 매칭하지 않습니다.
01

셀메이트 상품·옵션 파일 첨부

상품명 A열 · 옵션 B열 · 바코드번호 C열

셀메이트 CSV 파일을 먼저 선택해주세요.
02

미들웨어 판매처 파일 첨부

C열 채널명 기준 자동 분리 · GS, 네이버, 롯데온, 퀸잇, 하프클럽

통합 파일과 별도 네이버 파일을 차례로 선택해 추가할 수 있습니다.
03

상품 및 옵션 검증 · 결과 다운로드

일치 확인된 항목만 검증 완료 처리하고, 없는 품목과 옵션 불일치를 분리합니다.

두 종류의 파일을 첨부하면 바코드와 옵션을 비교할 수 있습니다.

0셀메이트 고유 바코드
0판매처 비교 행
0검증 완료
0검증 확인 필요
판매처엑셀 옵션 행검증 완료미확인·불일치 옵션
ZIP 안에 GS · 네이버 · 롯데온 · 퀸잇 · 하프클럽 엑셀을 각각 생성합니다. 원본 A~J열 + 검증 정보 K~T열.

한 파일에 여러 채널이 섞여 있어도 C열로 자동 분리합니다. 네이버 파일은 나중에 추가 선택해도 기존 통합 파일이 지워지지 않습니다. 파일 미첨부 채널은 미등록으로 간주하지 않습니다.

첨부 파일은 브라우저 안에서 처리합니다. 비교 결과는 실제 판매처 등록 여부를 직접 조회한 것이 아니라 첨부 엑셀에 기록된 품목코드와 옵션을 검증한 결과입니다.
