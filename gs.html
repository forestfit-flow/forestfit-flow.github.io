GS 패널티 사전 관리 v1.0

GS 전용 관리 사이트
GS 패널티 사전 관리용 파일을 업로드하면 지정된 컬럼 구조로 결과 파일을 생성합니다.
결과 파일 1행은 회색 배경 + 굵은 글씨로 출력됩니다.
아래 조건으로 조회한 파일을 업로드해 주시기 바랍니다.

[경로]
셀메이트 → 주문관리 → 판매처분류 : GS / GS더소재

[조회조건]
- 판매처분류 : GS / GS더소재
- 조회기간 : 임의기간 [ 3개월 전 ~ 조회일 기준 평일 2일 전 ]
- 확장필터 : 출고불가 필터 적용
한 줄에 하나씩 입력하세요. 납기일 계산 시 주말과 공휴일은 제외됩니다.
A 주문번호 B 주문일자 C 공급처명 D 지연일 E 사입상품명 F 판매상품명 G 옵션 H 입고예정일 I 납기일 J 납기 가능 여부 K 처리내용 L 메모1 M 메모2

결과 파일 사용 방법

J열 수식이 삭제되었거나 정상적으로 적용되지 않은 경우, 아래 수식을 J2 셀에 입력한 후 마지막 행까지 채워서 사용해 주시기 바랍니다.

=IF(OR(H2="",I2="",I2="취소확인요망"),"",IF(INT(IFERROR(DATEVALUE(TRIM(H2)),H2))>INT(IFERROR(DATEVALUE(TRIM(I2)),I2)),"출고 불가",""))
