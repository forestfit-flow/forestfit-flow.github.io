2026 사업계획서에서 선택한 월의 상품 키워드와 상품별 판매실적을 자동 채우고, 미매칭 상품은 추가 참고 엑셀까지 이어서 검색합니다.
작성일 · 부서 · 담당자까지 지정된 병합셀에 입력하며 원본 엑셀의 양식·병합·수식은 그대로 유지합니다.
파일은 서버로 전송되지 않고 브라우저에서만 처리됩니다.

추가 키워드 참고 엑셀 첨부 (선택)

키워드를 추가로 찾을 XLSX 파일을 첨부해주세요.
기존 사업계획서의 다른 월 탭에서 상품명이 매칭되지 않은 상품만 이 파일들에서 다시 찾습니다.
여러 파일을 한 번에 선택하거나 계속 추가할 수 있으며, 첨부한 순서대로 우선 사용합니다.
추가 참고 파일은 선택사항입니다.
검색 기준 · 추가 파일의 모든 시트에서 C:E 상품명을 찾고 F:G(핏) · H:I(소재) · J:K(디테일) · L:M(기능) 값을 읽습니다. 기존 월 탭에서 이미 정상 매칭된 상품은 추가 파일로 덮어쓰지 않습니다.
5

작성 정보 입력

작성일은 엑셀에 YYYY.MM.DD 형식으로 입력합니다. · T5:U5 작성일 · T6:U6 부서 · T7:U7 담당자
6

사업계획서 자동 입력

고정 입력 · CSV 합계 판매량 → E16:J16 · 판매금액 → E17:J17 · 작성일 → T5:U5 · 부서 → T6:U6 · 담당자 → T7:U7.
판매순위 자동 입력 · 3번 판매자료 CSV의 판매량을 상품명별로 합산한 뒤 내림차순 정렬하여 전체 / 데님 / 팬츠 / 슬랙스 / 스커트 각각 TOP5 상품명을 작성 월 탭의 순위 1~5위 C:E 병합셀에 자동 입력합니다. · 전체 판매순위는 24~28행을 사용하며 29행의 ‘기타’ 및 수식은 절대 수정하지 않습니다.
상품별 판매실적 · C:E 병합셀 상품명이 CSV의 상품명과 정확히 일치하면 같은 행 N:O 병합셀에 판매량, T:U 병합셀에 판매금액을 입력합니다. · 동일 상품이 여러 구역에 반복되면 모두 같은 판매실적을 입력합니다.
키워드 처리 · 첫 번째/두 번째 탭과 선택한 월 탭은 검색 원본에서 제외합니다. · 순위(B열)가 숫자인 행의 C:E 병합셀 상품명을 비교합니다. · 같은 상품을 찾으면 빈 F:G(핏), H:I(소재), J:K(디테일), L:M(기능)에 자동 입력합니다. · 판매순위 자동 변경으로 상품명이 바뀐 행은 이전 상품의 키워드가 남지 않도록 키워드칸을 비운 뒤 새 상품 기준으로 다시 채웁니다. · 상품명이 다른 탭 어디에도 매칭되지 않으면 빈 키워드칸을 노란색으로 표시하며, 사용자가 값을 입력하거나 붙여넣으면 노란색이 자동으로 사라집니다.
추가 참고 파일 · 기존 사업계획서의 다른 월 탭에서 같은 상품명을 찾지 못한 경우에만 4번에서 첨부한 추가 XLSX 파일을 순서대로 검색합니다. · 추가 파일에서 같은 상품을 찾으면 해당 키워드를 입력하고, 추가 파일에서도 찾지 못한 상품만 빈 키워드칸을 노란색으로 표시합니다.
카테고리 판별 · CSV의 상품명만 기준으로 분류합니다. · 데님: 데님·청바지·생지·노컷진·찐스판 포함 상품 → 37~41행 · 슬랙스: 슬랙스 포함 상품 → 59~63행 · 스커트: 스커트 포함 상품 → 70~74행 · 팬츠: 위 세 카테고리에 분류되지 않은 나머지 상품 중 판매량 상위 5개 → 48~52행. · ‘데님 스커트’처럼 단어가 겹치면 스커트가 우선이며, 75행은 합계행이라 절대 수정하지 않습니다.
