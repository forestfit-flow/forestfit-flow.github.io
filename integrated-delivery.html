품절 / GS / 기타채널 주문 파일의 동일 양식을 통합해 상품 단위로 정리한 뒤 사이트 안에서 대응 내용을 입력하고,
거래처별로 위에서 아래로 필요한 건만 처리합니다. 품절건은 입고일 입력 없이 대체 대응하고, 일반 납기건은 입고예정일이 준수일 이내면 업무목록에서 자동 제외합니다. 모든 주문번호는 끝까지 보존됩니다.

UNIFIED V2.21 · 입고일 입력 후 단계 자동이동 · 주문별 납기판정

1. 품절 품절 주문 파일

이 파일의 모든 주문은 문제 주문으로 분류합니다. 사용자정의1 · 사입상품명 · CS일자를 읽어 CS 안내 여부를 분석합니다. 품절 파일은 입고예정일 컬럼이 없어도 정상 인식합니다.

선택된 파일 없음

2. GS GS 납기 파일

신규 공통 양식의 사용자정의1 · 사입상품명 · 입고예정일을 읽습니다. GS 출고준수일은 주문일 기준 주말·공휴일을 제외하고 +8영업일로 계산합니다.

선택된 파일 없음

3. 기타채널 기타채널 납기 파일

GS를 제외한 채널 주문의 신규 공통 양식에서 주문번호별 입고예정일을 읽고, 채널별 출고준수일과 비교합니다.

선택된 파일 없음

4. 비플로우 출고준수일 파일

실제 b-flow 주문 내역 양식을 기준으로 주문번호를 매칭합니다. 비플로우 기본 출고준수일은 주문일 +5일이며, 보조 파일의 T열 출고예정일은 별도 참고값으로 표시합니다.

선택된 파일 없음 · 선택사항
인식 컬럼: 주문번호 / 판매채널 / 상품명 / 옵션정보 / 출고예정일 · 열 위치가 바뀌어도 헤더명으로 자동 인식

5. 어제 결과 이전 입력 파일

어제 내려받은 CS전달 엑셀을 선택하면 같은 상품+옵션의 이전 내용을 오늘 화면에서 참고용으로 보여줍니다. 자동 반영하지 않으며, 필요한 건만 [어제 값 그대로 입력] 버튼으로 복사할 수 있습니다.

선택된 파일 없음 · 선택사항
어제 값은 기본적으로 보기 전용입니다. [어제 값 그대로 입력]을 직접 누른 상품만 오늘 입력칸에 복사됩니다.

계산 설정

기타채널 지연 및 GS·퀸잇 고객 안내기한 경과 판정에 사용합니다.
토·일은 자동 제외합니다. GS/기타채널 영업일 계산에 공통 적용됩니다.
현재 페이지에서 임시 유지 · 재계산해도 입력값이 사라지지 않습니다.
품절건: 입고예정일 없이 [다른 옵션 입력 / 대체품 입력 / 해당없음] 메뉴칩 중 하나를 선택해 대응합니다.
업무 단계: ① 입고일정 기입 → ② 대체품 / 옵션 변경 상품 순서로 처리합니다. 품절건은 바로 ②에 표시됩니다.
일반 납기건: ① 입고일정 기입에서 날짜를 입력합니다. 출고준수일 이내면 자동 제외되고, 납기 초과면 ②로 이동합니다. [입고일정 확인불가 → 2번 탭 이동]을 누른 건도 즉시 ②로 이동해 대체품/옵션 변경을 확인합니다. 잘못 입력해 제외된 건은 [납기 내 입고 · 되돌리기] 탭에서 수정할 수 있습니다.
CS 이력: 신규 양식의 CS일자를 최근 상담일로 표시하고, CS메모에 대체품/다른 옵션 안내내용이 있으면 사이트에 함께 보여주며 입력칸에도 안전하게 반영합니다.
입고예정일: GS/기타채널 파일의 마지막 열 재고매칭(1)입고예정일을 주문번호별 입고일로 읽습니다. 품절 파일은 해당 컬럼이 없어도 됩니다. 일반 납기건은 비어 있으면 ① 입고일정 기입, 출고준수일보다 늦으면 ② 대체품 / 옵션 변경 상품으로 자동 분류합니다.
CS 전달내용: 한 줄 요약으로 자동 작성하며 필요할 때만 수정합니다. 처리결과 공유 문구는 넣지 않습니다.
확인 필요 품번 파일: 원본 파일을 모두 불러온 뒤 [확인 필요 품번 엑셀 다운로드]를 누르면 주문별 입고예정일 판정 결과를 기준으로 입고일 미기입 / 납기일정 초과 / 품절만 내려받습니다. 같은 품번에 미기입 주문과 초과 주문이 섞여 있으면 구분별로 각각 표시합니다.
어제 참고: 이전 입력 파일을 선택하면 같은 상품+옵션의 어제 내용을 카드에서 참고할 수 있습니다. 어제 값은 오늘 입력칸에 자동 반영하지 않습니다. 상품+옵션이 같고 거래처 또는 사입상품명까지 일치할 때만 참고를 표시하며, 필요할 때 [어제 값 그대로 입력] 버튼으로 해당 상품에만 복사할 수 있습니다. 현재 페이지에서 입력한 값은 재계산해도 유지됩니다.
출고준수일 기준: 퀸잇 주문일 +21영업일 / GS 주문일 +8영업일(단, +8영업일 날짜가 금요일 또는 공휴일 전날이면 +7영업일) / 네이버·롯데ON 주문일 +1개월 / 하프클럽 주문일 +15영업일 / 비플로우 주문일 +5일입니다. 퀸잇 고객 안내기한은 사용자정의1 다음 영업일, GS 고객 안내기한은 주문일 다음 2영업일 이내로 유지합니다.
